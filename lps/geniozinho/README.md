## Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias principais:

- **[Vite](https://vitejs.dev/)**: Ferramenta de build rápida e leve.
- **[React](https://react.dev/)**: Biblioteca JavaScript para criar interfaces de usuário.
- **[TypeScript](https://www.typescriptlang.org/)**: Superset tipado do JavaScript.
- **[Tailwind CSS](https://tailwindcss.com/)**: Framework de CSS utilitário para estilização rápida.
- **[shadcn/ui](https://ui.shadcn.com/)**: Componentes de interface reutilizáveis e acessíveis.
- **[Firebase](https://firebase.google.com/)**: Plataforma para hospedagem e serviços backend.

## Começando

Siga estas instruções para configurar e rodar o projeto localmente.

### Pré-requisitos

- Node.js e npm instalados.

### Instalação

Clone o repositório e instale as dependências:

```bash
git clone <URL_DO_SEU_REPOSITORIO>
cd digito-web-geniozinho
npm install
```

### Desenvolvimento Local

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

O aplicativo estará disponível em `http://localhost:5173` (ou outra porta indicada no terminal).

## Build e Deploy

Os processos de build e deploy foram simplificados. Para um guia detalhado, consulte o arquivo [CONTRIBUTING.md](./CONTRIBUTING.md).

### Resumo Rápido

1.  **Build** (Gera os arquivos de produção na pasta `dist`):

    ```bash
    npm run build
    ```

2.  **Deploy** (Envia para o Firebase Hosting):
    ```bash
    firebase deploy
    ```
